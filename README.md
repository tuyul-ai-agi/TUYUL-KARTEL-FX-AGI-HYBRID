## 🚀 Instalasi & Setup

### 1️⃣ Kloning Repository

```bash
git clone https://github.com/tjx578/TUYUL-KARTEL-FX-AGI-HYBRID.git
cd TUYUL-KARTEL-FX-AGI-HYBRID
```

### 2️⃣ Instalasi Dependensi

```bash
pip install -r requirements.txt
```

### 3️⃣ Konfigurasi Environment

Buat file `.env` berisi:

```env
HYBRID_API_TOKEN=your-hybrid-token
OPENAI_API_KEY=your-openai-key
GITHUB_TOKEN=your-github-token
GH_REPO=tjx578/TUYUL-KARTEL-FX-AGI-HYBRID
GPT_MODEL=gpt-5-turbo
```

### 4️⃣ Jalankan Tes Sinkronisasi

```bash
python client_agi_hybrid.py
```

Jika berhasil, sistem akan menampilkan:

```
Tri-Vault Sync: SUCCESS
Reflex–Fusion–Reflective coherence: 0.91
GitHub Workflow Dispatch: OK
```
