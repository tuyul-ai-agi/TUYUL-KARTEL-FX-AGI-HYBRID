```bash

bash scripts/sync_hybrid_repo.sh
```

Opsi yang dapat dioverride:

- `REPO_SLUG` (default: `tjx578/TUYUL-KARTEL-FX-AGI-HYBRID`)
- `BRANCH_NAME` (default: `main`)
- `TARGET_DIR` (default: `vaults/hybrid_repo`)
